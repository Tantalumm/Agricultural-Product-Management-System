# Project Name
Agricultural-Product-Management-System
This project is a foundational practice in building CRUD operations, developed to manage agrochemical products. It uses Java for the backend logic and JavaScript for the frontend user interface.

## 🛠️ Tech Stack

- **Frontend:** React 19, Bootstrap 5
- **Backend:** Java 17, Spring Boot 3.5.6
- **Database:** MySQL
- **ORM:** Hibernate / JPA

---

## ✨ Features

- User Authentication
- Item Management
- Search and Pagination
